# Tashi Portfolio

A simple, responsive personal portfolio website to showcase projects and provide a contact form.

## Features

- **Project showcase** — card grid displaying featured work with category badges
- **Contact form** — fields for name, email, subject, and message
- **Responsive layout** — adapts from single-column on mobile to three-column on desktop
- **Hover interactions** — card lift effect and button state transitions

## Tech Stack

- HTML5
- CSS3 (Grid, Flexbox, media queries)
- No frameworks or dependencies

## Structure

```
├── index.html
└── style.css
```

## Usage

Open `index.html` directly in a browser — no build step required.
